# Posting Plan Guide

Heuristics for ordering a video series and setting cadence. These were established from the channel's initial strategy session and should stay consistent across projects.

## Ordering heuristics (apply in this priority order)

1. **Strongest hook goes first.** The first video for any new project (or the channel's very first video overall) should be the one with the most immediately gripping hook — usually a Pillar 1 (Decision) video that states a counter-intuitive choice ("I could've done the easy thing. I didn't.") works best as an opener because it signals the channel's whole identity in one video.
2. **Save/share-bait early, not last.** Indie Math videos (concrete numbers) tend to get saved and shared more than they get watched-to-completion — put at least one in the first 3-4 slots of any series so the algorithm gets an early signal of shareability, rather than saving all the numbers content for later.
3. **Differentiator pillar (Building for SEA) within the first week.** If the project has Pillar 2 content, surface it early — it's the channel's biggest differentiator versus generic coding-tip accounts, and waiting too long to show it means early viewers judge the channel against Fireship-style competitors instead of recognizing the unique angle.
4. **Don't cluster by pillar.** Alternate pillars across the posting order rather than doing "all Decision videos, then all SEA videos, then all Math videos" — variety keeps a multi-day series from feeling repetitive to anyone watching multiple entries close together.
5. **End-of-week or end-of-series slot can be lighter/behind-the-scenes.** If there's a process-oriented candidate (e.g. the three-document planning habit), it works well as a lower-stakes close to a posting run rather than as an opener.

## Cadence guidance

- **Brand-new channel, no posting history:** 1 video/day for the first week. Consistency signals matter more than any single video's performance while the algorithm is still learning who to show the channel to.
- **Channel already has history/traction:** 4–5 videos/week sustainable cadence. Don't recommend daily posting indefinitely — ask the user which situation applies if it's not already established in the conversation.
- **A single small series for one project (e.g. 6-8 videos) feeding into an existing channel:** treat it as a content batch to slot into the existing cadence, not a new posting sprint — don't recommend the new-channel daily cadence unless the user confirms this actually is a new channel or a relaunch.

## Bio/CTA setup (state this once per series, not per video)

- Bio should state the channel promise in one line, not a list of all products (e.g. "Building real apps for SEA. Indie dev, no fluff.")
- Link in bio should point to a single landing page / single current waitlist — not a full portfolio with five options. One clear next action converts better than several.
- Per-video CTAs (in the script itself or in a first-comment) should reference only the product that specific video is about — never link multiple products from one video's CTA.

## What not to do

- Don't open a new project's series with a "channel intro" or "let me explain what I'm doing" video — the first real story-video should do that work implicitly. A meta-intro video gets little algorithmic reach and delays the first real hook.
- Don't post two videos about the same specific decision/number close together, even from different angles — let the audience accumulate distinct facts about the product, not repeated reinforcement of one fact.
